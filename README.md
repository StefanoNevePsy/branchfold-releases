# Branchfold · Download

Scarica l’ultima versione per macOS, Windows x64 e Android ARM64 dalla pagina [Release](https://github.com/StefanoNevePsy/branchfold-releases/releases/latest).

Branchfold è un editor per mappe mentali e concettuali. Questo repository ospita i pacchetti dell’app, le note di rilascio e i riferimenti dei componenti distribuiti con essa.

## Componenti di terze parti

Branchfold utilizza le librerie condivise di [Qt 6.8.3](https://doc.qt.io/qt-6.8/licenses-used-in-qt.html). I [sorgenti corrispondenti di Qt](https://download.qt.io/archive/qt/6.8/6.8.3/single/) sono disponibili presso il progetto Qt. I testi di licenza accompagnano i pacchetti. I font Gloock, Archivo e La Belle Aurore sono distribuiti secondo la SIL Open Font License. L’immagine dimostrativa è [Bee on lavender](https://commons.wikimedia.org/wiki/File:Bee_on_lavender_(Unsplash).jpg) di Jenna Lee, CC0.
